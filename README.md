# Smart Inventory and Stock Management System

## Project Overview
This project is a web-based inventory and stock management system developed using Java, Spring Boot, and MySQL. It helps manage products, stock levels, and inventory records efficiently.

## Features
- Add Products
- Update Product Details
- Delete Products
- Stock Management
- Low Stock Alerts
- Responsive User Interface

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- HTML

## How to Run the Project

1. Clone the repository
2. Open the project in Spring Tool Suite or IntelliJ
3. Configure MySQL database
4. Run the Spring Boot application
5. Open browser and visit:

http://localhost:8080
